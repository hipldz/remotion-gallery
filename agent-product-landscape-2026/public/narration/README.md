# 浏览器真人配音与字幕编辑

运行 `npm run preview`，用 Chrome 或 Edge 打开终端地址。右侧支持整片或 35 段口播，当前初始时长 7:36。

本地 `vendor/remotion-voiceover-0.2.1.tgz` 的“编辑稿件与时长”支持改正文、增删句子、设置每句起点与持续秒数。**最新正文和实际时间在本目录的 `manifest.json`，保存内容优先于源码初始稿。** 后续字幕、镜头与逐镜录音随调整顺延。

原版截图切换、工具往返、修改验收和任务分裂读取对应句子的实际切点，动作进入之后保持构图，连续环绕与悬浮继续播放。延长字幕会延长阅读画面。

默认“按朗读节奏”。允许麦克风，倒计时后跟高亮提词朗读，用“读完，下一句”或空格打点；超过原区间仍可继续，停止后按实际朗读延长。选“按画面时长”会在区间结束时自动停止。

先“跟画面试听”，再“保存并使用”，也可下载 WAV。录制时影片静音。接口支持 256 MB，可保存本片的 48 kHz 单声道录音。刷新预览、Studio 和章节合成都载入同一清单。

逐镜重录覆盖对应镜头，短录音剩余区间留白；移除后恢复整片或外部录音。整片配音覆盖外部录音，逐镜配音覆盖整片中对应镜头。重录或移除只更新清单，旧 WAV 原件保留，清单与录音默认忽略。

导出最新字幕运行 `npm run captions`。普通初始稿同步不会覆盖本目录已有编辑。
