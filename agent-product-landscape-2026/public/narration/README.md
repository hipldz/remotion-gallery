# 浏览器真人配音

在项目目录运行 `npm run preview`，用 Chrome 或 Edge 打开终端地址。右侧录音面板支持整片或 31 个有旁白的镜头，提词与影片字幕共用分镜数据。

点击“开始录音”并允许麦克风，倒计时后跟画面朗读。在当前区间结束时自动停止，也可以提前停止。先“跟画面试听”，再“保存并使用”；也可以下载 WAV。

保存接口将 `manifest.json` 和单声道 WAV 写入本目录。刷新后继续使用，Studio 和独立章节刷新后也会载入。重录或移除只更新清单，保留旧 WAV 原件。清单与录音默认忽略，不提交 Git。

每段录制包含镜头开头的留白，请跟随高亮提词开始说话。录制范围采用当前剪辑长度，不自动延长镜头。需要更长的时间时，先调整 `src/data/shots.json`，或继续使用 `public/vo/` 的外部录音与弹性时长流程，再开始浏览器录音。

逐镜重录会覆盖对应镜头的整段人声，短录音剩余区间留白；移除后恢复已有的整片配音或外部录音。整片配音覆盖外部录音，逐镜配音可继续覆盖整片中的对应镜头。请先确定剪辑时长，再录制整片。
