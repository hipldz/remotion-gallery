# Workflow vs Agent 真人配音

运行 `npm run preview`，在 Chrome / Edge 打开 `http://127.0.0.1:4175/`。录音面板提供整片或 37 个有字幕的镜头，提词使用本项目的 91 条字幕，已去掉 Markdown 加粗标记。

选择范围，点击“开始录音”并允许麦克风。3 秒倒计时后跟随画面与高亮提词朗读，在区间末尾自动停止，也可以提前停止。先“跟画面试听”，满意后“保存并使用”或下载 WAV。保存后可“录下一段”。

录音和 `manifest.json` 保存在本目录，刷新预览页即可恢复。Remotion Studio 的全片和 11 个独立章节刷新后也会加载。录制期间影片静音，跳转和播放控制暂停使用；配音播放时背景音乐降低音量。“配乐与音效”开关仅控制音乐与短音效，人声继续播放。

逐镜重录会覆盖对应镜头的整段人声；短录音的剩余区间留白。移除逐镜录音后，已有整片录音会恢复。重录或移除只更新清单，保留旧 WAV 原件。本目录的录音与清单默认不提交 Git，也不会写入其他视频工程。

录制沿用当前 5:40 剪辑，不自动延长镜头。请先确定分镜时长，再录整片。字幕仍按现有分镜时间显示，未做语音强制对齐。
