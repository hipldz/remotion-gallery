# Workflow vs Agent 演示入口

本入口复用现有 `Film`，通过 [`remotion-presentation`](../../remotion-presentation/) 控制播放区间和停留点。默认关闭字幕、配乐、音效和旁白。工具栏的「开始录制」可以录下演示操作和你的麦克风声音。

在目标工程已有依赖可用的情况下启动：

```bash
cd workflow-vs-agent
pnpm presentation
```

打开 `http://127.0.0.1:4176/`。演示有独立入口、端口和 Vite 配置，不使用预览页的录音插件。字体与图片继续来自本工程的 `public/`。

第一版通过相对路径引用工具包源码，不新增本地 `file:` 依赖，不需要先构建工具包。Vite 的别名和去重配置让共享源码复用目标工程已有的 React、Remotion 和 Player。未安装依赖的环境需由使用者先按工程说明准备依赖。

## 录制

先选演示起点，点 **开始录制**，在浏览器中选择当前演示标签页并允许麦克风。计时开始后可以按 F 全屏，用方向键或翻页笔操作。结束时按 **Shift+R**、点「停止录制」，或在浏览器中点「停止共享」。工具栏恢复后点 **下载视频**。成片包含实际运镜、回退、停留和你的讲解声。

## 调整内容

- `adapter.ts`：导入原 `Film`、固定原始时间轴，并传入关闭字幕和声音的参数。`voiceTracks: []` 同时跳过旁白清单读取。
- `cues.ts`：目标工程自己的演讲顺序和停留点。偏移量以原分镜内的秒数填写，转换为整数帧后交给通用演示壳。追加分步展开时，在同一分镜中增加区间即可。
- `vite.config.ts`：入口、素材目录、目标依赖解析与独立端口。

配置覆盖全片主要概念，跳过求关注镜头和两秒章节卡。停留点依据现有场景中的入场、连线、运镜和高亮时序选取；它们尚未经浏览器视觉校准，录制前应顺序检查，并按实际画面调整。部分图形标签与画面高亮仍由原场景驱动，它们属于画面内容，并非字幕层。

原视频重剪或动画时序改变后，需要重新校准 `cues.ts`；演示工具不修改原 `src/`、分镜、配音配置或配音工具。使用 `pnpm typecheck:presentation` 可单独检查该入口的 TypeScript。
